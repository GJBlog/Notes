# Flutter

### 特点

* 是谷歌主导研发的一个多平台UI工具包

### 快捷键(Mac平台)

1、AndriodStudio中

* 快速修改Widget类型

```shell
Alt + Enter
```

* 查看某个抽象类的实现类

```shell
Option + Command + B
```

* 给Widget外层添加Container

```shell
Option + Enter
```

* 抽取新的Widget

```shell
Option + Command + w
默认情况下，AndriodStudio中会与kotlin中冲突，需要删除下
```
